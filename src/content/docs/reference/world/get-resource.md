Gets a named resource from the World.

```lua
resource = world:getResource( name )
```

### Arguments

| Name | Type | Description |
| --- | --- | --- |
| `name` | string | Name of the resource |

### Returns

| Name | Type | Description |
| --- | --- | --- |
| `resource` | any | The resource, or nil if none was set |
