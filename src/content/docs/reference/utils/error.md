Raises a formatted error.

```lua
Utils.error( level, str, ... )
```

### Arguments

| Name | Type | Description |
| --- | --- | --- |
| `level` | integer | Error level passed to error(), plus one |
| `str` | string | Format string |
| `...` | any | Format arguments |
