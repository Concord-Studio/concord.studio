[← Type](/api/type)

Returns true if the value is a World instance.

Use when validating optional world arguments to `Entity.new` or custom helpers.

```lua
isWorld = Type.isWorld( t )
```

### Arguments

| Name | Type | Description |
| --- | --- | --- |
| `t` | any | Object to check |

### Returns

| Name | Type | Description |
| --- | --- | --- |
| `isWorld` | boolean |  |
