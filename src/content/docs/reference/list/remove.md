Removes an object from the List.

```lua
list:remove( obj )
```

### Arguments

| Name | Type | Description |
| --- | --- | --- |
| `obj` | any | Object to remove |

### Returns

| Name | Type | Description |
| --- | --- | --- |
|  | [List](/api/list#list)\|nil | Returns self if removed; nil if the object was not in the List |
