Returns the object at an index.

```lua
obj = list:get( i )
```

### Arguments

| Name | Type | Description |
| --- | --- | --- |
| `i` | integer | Index to get from |

### Returns

| Name | Type | Description |
| --- | --- | --- |
| `obj` | any | Object at the index |
