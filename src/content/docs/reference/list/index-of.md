Returns the index of an object in the List.

Errors if the object is not in the List.

```lua
integer = list:indexOf( obj )
```

### Arguments

| Name | Type | Description |
| --- | --- | --- |
| `obj` | any | Object to get index of |

### Returns

| Name | Type | Description |
| --- | --- | --- |
| `integer` | integer | index of object in the List. |
