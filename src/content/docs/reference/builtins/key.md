## Require

If the `concord` folder is in the root directory of your game, you can import this module like so:

```lua
Key = require('concord.builtins.key')
```

## Key

The Entity must belong to a World. Calling the Component returns the key value.
On `:give("key", key?)`, an omitted key is generated by the World; an explicit key is registered if free.

Extends [ComponentClass](/api/component/component-class).

## Methods

| Method | Description |
| --- | --- |
| [Key:deserialize](/api/builtins/key/deserialize) | Assigns a key from serialized data. |
| [Key:removed](/api/builtins/key/removed) | Callback: Clears the World key when the Component is removed (not replaced). |
